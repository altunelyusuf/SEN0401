The '''Lightning Network''' ('''LN''') is a payment protocol built on the [[bitcoin]] [[blockchain]].<ref name=":0">{{Cite web|title=lightningnetwork/lnd|url=https://github.com/lightningnetwork/lnd|access-date=2021-05-04|website=GitHub|language=en|archive-date=2022-07-12|archive-url=https://web.archive.org/web/20220712135634/https://github.com/lightningnetwork/lnd|url-status=live}}</ref> It is intended to enable fast transactions among participating nodes (independently run members of the network) and has been proposed as a solution to the [[bitcoin scalability problem]].<ref>{{Cite web|url=https://www.bloomberg.com/news/articles/2018-03-15/technology-meant-to-make-bitcoin-money-again-is-going-live-today|title=Technology Meant to Make Bitcoin Money Again Is Now Live|last=Russo|first=Camila|date=March 15, 2018|website=www.bloomberg.com|access-date=2019-12-12|archive-date=2018-03-31|archive-url=https://web.archive.org/web/20180331110223/https://www.bloomberg.com/news/articles/2018-03-15/technology-meant-to-make-bitcoin-money-again-is-going-live-today|url-status=live}}</ref><ref>{{Cite web|url=https://fortune.com/2019/01/17/unit-e-cryptocurrency-news-bitcoin/|title=MIT and Stanford Professors Are Designing a Cryptocurrency to Top Bitcoin: Unit-e|date=January 17, 2019|website=fortune.com|access-date=2019-12-12|archive-date=2021-10-06|archive-url=https://web.archive.org/web/20211006162801/https://fortune.com/2019/01/17/unit-e-cryptocurrency-news-bitcoin/|url-status=live}}</ref><ref name= PriceSurge>{{cite news|last=Popper|first=Nathaniel|title=Bitcoin price surges after deal on software updates|url=https://www.newspapers.com/clip/40494024/article_about_lightning_network|date=August 15, 2017|publisher=The Boston Globe|access-date=December 12, 2019|archive-date=December 13, 2019|archive-url=https://web.archive.org/web/20191213020556/https://www.newspapers.com/clip/40494024/article_about_lightning_network/|url-status=live}}</ref>

== History ==
Joseph Poon and Thaddeus Dryja published a Lightning Network white paper in February 2015.<ref>{{cite web|url=http://lightning.network/|title=Lightning Network whitepaper 0.5 by Joseph Poon and Thaddeus Dryja|date=28 February 2015|archive-url=https://web.archive.org/web/20150228162703/http://lightning.network/|archive-date=2015-02-28}}</ref><ref name=":1" />

Lightning Labs launched the Lightning Network in 2018 with the goal of reducing the cost and time required for cryptocurrency transactions. Specifically, the bitcoin blockchain can only process around 7 transactions per second (compared to [[Visa Inc.]], which can process around 24,000 transactions per second). Despite initial enthusiasm for the Lightning Network, reports on social media of failed transactions, security vulnerabilities, and over-complication led to a decline in interest.<ref name="Xie-2023">{{cite news |last1=Xie |first1=Teresa |title=Bitcoin's Lightning Network Scaling Solution Seeks Resurgence After Losing Way |url=https://finance.yahoo.com/news/bitcoin-lightning-network-scaling-solution-111025791.html |access-date=13 May 2024 |work=Bloomberg |date=16 October 2023 |via=Yahoo News |archive-date=13 May 2024 |archive-url=https://web.archive.org/web/20240513214721/https://finance.yahoo.com/news/bitcoin-lightning-network-scaling-solution-111025791.html |url-status=live }}</ref>

The three major Lightning Network implementations are Lightning Network Daemon (LND) by Lightning Labs, Core Lightning (CLN) by [[Blockstream]], and Eclair by ACINQ. A fourth implementation library, Lightning Development Kit (LDK), is maintained by Spiral, a subsidiary of [[Block, Inc.]]<ref>{{cite book |last1=Antonopoulos |last2=Osuntokun |last3=Pickhardt |title=Mastering the Lightning Network |publisher=O'Reilly Media |year=2022 |isbn=978-1-4920-5486-3}}</ref>

On January 19, 2019, pseudonymous [[Twitter]] user hodlonaut began a game-like promotional test of the Lightning Network by sending 100,000 [[Bitcoin#Units_and_divisibility|satoshis]] (0.001 bitcoin) to a trusted recipient where each recipient added 10,000 satoshis ($0.34 at the time) to send to the next trusted recipient. The "lightning torch" payment reached notable personalities including former Twitter A.K.A X CEO [[Jack Dorsey]], [[Litecoin]] Creator [[Charlie Lee (computer scientist)|Charlie Lee]], Lightning Labs CEO Elizabeth Stark, and [[Binance]] CEO "CZ" Changpeng Zhao, among others.<ref name="CNBCTorch">{{cite web |last1=Browne |first1=Ryan |title=Jack Dorsey says the 'only' cryptocurrency he owns is bitcoin |url=https://www.cnbc.com/2019/02/06/jack-dorsey-says-the-only-cryptocurrency-he-owns-is-bitcoin.html |website=CNBC |access-date=17 December 2019 |language=en |date=6 February 2019 |archive-date=15 August 2021 |archive-url=https://web.archive.org/web/20210815145815/https://www.cnbc.com/2019/02/06/jack-dorsey-says-the-only-cryptocurrency-he-owns-is-bitcoin.html |url-status=live }}</ref><ref name="FortuneTorch">{{cite web |last1=Hackett |first1=Robert |last2=Roberts |first2=Jeff John |last3=Wieczner |first3=Jen |title=The Ledger: Cryptocurrency Custody, QuadrigaCX Quagmire, CEOs Pass Bitcoin 'Torch' |url=https://fortune.com/2019/02/12/the-ledger-cryptocurrency-custody-quadrigacx-quagmire-ceos-pass-bitcoin-torch/?.com |website=Fortune |publisher=Fortune Magazine |access-date=17 December 2019 |language=en |archive-date=1 June 2022 |archive-url=https://web.archive.org/web/20220601162309/https://fortune.com/2019/02/12/the-ledger-cryptocurrency-custody-quadrigacx-quagmire-ceos-pass-bitcoin-torch/?.com }}</ref>

==Design==

[[Andreas Antonopoulos]] calls the Lightning Network a second layer routing network.<ref name="MasteringBitcoin" /> The payment channels allow participants to transfer money to each other without having to make all their transactions public on the [[blockchain]].<ref>{{Cite magazine|url=https://www.wired.com/story/the-lightning-network-could-make-bitcoin-faster-and-cheaper/|title=The Lightning Network Could Make Bitcoin Faster—and Cheaper|magazine=Wired|access-date=2019-12-12|language=en|issn=1059-1028|archive-date=2021-11-25|archive-url=https://web.archive.org/web/20211125204349/https://www.wired.com/story/the-lightning-network-could-make-bitcoin-faster-and-cheaper/|url-status=live}}</ref><ref>{{Cite news|url=https://www.bloomberg.com/news/articles/2019-01-17/mit-stanford-academics-design-cryptocurrency-to-better-bitcoin|title=MIT, Stanford Academics Design Cryptocurrency to Better Bitcoin|work=Bloomberg|access-date=2019-12-12|language=en|archive-date=2021-10-06|archive-url=https://web.archive.org/web/20211006231926/https://www.bloomberg.com/news/articles/2019-01-17/mit-stanford-academics-design-cryptocurrency-to-better-bitcoin|url-status=live}}</ref> This is secured by penalizing uncooperative participants. When opening a channel, participants must commit an amount on the blockchain (a ''funding transaction'').<ref name="ScalableFunding">{{cite journal |last1=Burchert |first1=Conrad |last2=Decker |first2=Christian |last3=Wattenhofer |first3=Roger |title=Scalable Funding of Bitcoin Micropayment Channel Networks |journal=Royal Society Open Science |volume=5 |issue=8 |article-number=180089 |date=August 29, 2018 |url=https://www.tik.ee.ethz.ch/file/a20a865ce40d40c8f942cf206a7cba96/Scalable_Funding_Of_Blockchain_Micropayment_Networks%20(1).pdf |access-date=17 December 2019 |doi=10.1098/rsos.180089  |doi-access=free|pmid=30225004 |pmc=6124062 |bibcode=2018RSOS....580089B |archive-date=28 June 2019 |archive-url=https://web.archive.org/web/20190628001445/https://www.tik.ee.ethz.ch/file/a20a865ce40d40c8f942cf206a7cba96/Scalable_Funding_Of_Blockchain_Micropayment_Networks%20(1).pdf }}</ref> Time-based script extensions like [[Bitcoin#2015–2019|<code>CheckSequenceVerify</code>]] and <code>CheckLockTimeVerify</code> make the penalties possible.

Transacting parties use the Lightning Network by opening a payment channel and transferring (committing) funds to the relevant layer-1 blockchain (e.g. bitcoin) under a [[smart contract]]. The parties then make any number of off-chain Lightning Network transactions that update the tentative distribution of the channel's funds, without broadcasting to the blockchain. Whenever the parties have finished their transaction session, they close the payment channel, and the smart contract distributes the committed funds according to the transaction record.<ref name=":1">{{Cite web|url=https://arstechnica.com/tech-policy/2018/02/bitcoins-lightning-network-a-deep-dive/|title=Bitcoin has a huge scaling problem—Lightning could be the solution|last=Lee|first=Timothy B.|date=2018-02-04|website=Ars Technica|language=en-us|access-date=2019-12-12|archive-date=2021-09-01|archive-url=https://web.archive.org/web/20210901155533/https://arstechnica.com/tech-policy/2018/02/bitcoins-lightning-network-a-deep-dive/|url-status=live}}</ref>

== Implementations ==
===Benefits===
According to bitcoin advocate [[Andreas Antonopoulos]], the Lightning Network provides several advantages over on-chain transactions:
*Granularity – According to Andreas Antonopoulos, some implementations of the Lightning Network allow for payments that are smaller than a satoshi, the smallest unit on the base layer of bitcoin.<ref name="MasteringBitcoin" />
*Privacy – Lightning network payments may be routed through many sequential channels where each node operator will be able to see payments across their channels, but they will not be able to see the source nor destination of those funds if they are non-adjacent.<ref name="MasteringBitcoin">{{cite book |last1=Antonopoulos |first1=Andreas |title=Mastering Bitcoin |date=2017-07-21 |publisher=O'Reilly |isbn=978-1-4919-5438-6 |pages=297–304 |edition=2nd }}</ref>
*Speed – Settlement time for lightning network transactions is under a minute and can occur in milliseconds.<ref name="MasteringBitcoin" /> Confirmation time on the bitcoin blockchain, for comparison, occurs every ten minutes, on average.
*Transaction throughput – There are no fundamental limits to the amount of payments per second that can occur under the protocol. The amount of transactions are only limited by the capacity and speed of each node.<ref name="MasteringBitcoin" />

===Limitations===
The Lightning Network (LN) operates through bidirectional payment channels between two nodes, forming smart contracts that facilitate off-chain transactions. If either party closes a channel, the final state is settled on the Bitcoin blockchain.<ref>{{cite book |last1=Antonopoulos |first1=Andreas |last2=Osuntokun |first2=Olaoluwa |last3=Pickhardt |first3=René |date=January 4, 2022 |title=Mastering the Lightning Network: A Second Layer Blockchain Protocol for Instant Bitcoin Payments |edition=1st |publisher=O'Reilly Media |chapter=How the Lightning Network Works |chapter-url=https://github.com/lnbook/lnbook/blob/firstedition_firstprint/03_how_ln_works.asciidoc |isbn=978-1-4920-5486-3 |access-date=May 16, 2022 |archive-date=July 1, 2022 |archive-url=https://web.archive.org/web/20220701182317/https://github.com/lnbook/lnbook/blob/firstedition_firstprint/03_how_ln_works.asciidoc |url-status=live }}</ref>  While this design enables faster and cheaper transactions, the necessity of on-chain transactions to open and close channels introduces scalability constraints.<ref>{{cite conference

=== Routing ===
To preserve privacy and security, the network employs an '''[[onion routing]]''' protocol, wherein each node in the path decrypts only enough information to determine the next hop, without knowledge of the payment's origin or final destination.<ref>{{cite book |last1=Antonopoulos |first1=Andreas |last2=Osuntokun |first2=Olaoluwa |last3=Pickhardt |first3=René |date=January 4, 2022 |title=Mastering the Lightning Network: A Second Layer Blockchain Protocol for Instant Bitcoin Payments |edition=1st |publisher=O'Reilly Media |chapter=Chapter 8: Routing on a Network of Payment Channels |chapter-url=https://github.com/lnbook/lnbook/blob/firstedition_firstprint/08_routing_htlcs.asciidoc |isbn=978-1-4920-5486-3 |access-date=May 16, 2022 |archive-date=June 4, 2022 |archive-url=https://web.archive.org/web/20220604170233/https://github.com/lnbook/lnbook/blob/firstedition_firstprint/08_routing_htlcs.asciidoc |url-status=live }}</ref>

{{As of|2026|3}}, the Lightning Network had over 17,000 public nodes and approximately 40,000 public payment channels, with a total network capacity of around 4,900 [[Bitcoin|BTC]].<ref>{{cite web |url=https://mempool.space/lightning |title=Lightning Network Dashboard |website=mempool.space |access-date=2026-03-22}}</ref>

==Use cases==
Bitcoin was originally intended to be a [[peer-to-peer]] electronic cash system. A notable early example occurred in May 2010 when [[Laszlo Hanyecz]] paid 10,000 BTC for two pizzas<ref>{{Cite web |last=Russo |first=Camila |date=February 27, 2018 |title=Crypto Legend Who Bought Pizza With 10,000 Bitcoin Is Back At It |url=https://www.bloomberg.com/news/articles/2018-02-26/crypto-legend-who-bought-pizza-with-10-000-bitcoin-is-back-at-it |url-status=live |archive-url=https://web.archive.org/web/20220223094714/https://www.bloomberg.com/news/articles/2018-02-26/crypto-legend-who-bought-pizza-with-10-000-bitcoin-is-back-at-it |archive-date=2022-02-23 |access-date=2019-12-12 |website=Bloomberg}}</ref>—an event now noted annually as ''Bitcoin Pizza Day''.{{Relevance inline|date=October 2025}} As Bitcoin's value and network congestion increased, this use was no longer practical.<ref>{{cite web |url=https://arstechnica.com/tech-policy/2018/02/bitcoins-lightning-network-a-deep-dive/ |title=Bitcoin has a huge scaling problem—Lightning could be the solution |last=Lee |first=Timothy B. |date=2018-02-04 |website=Ars Technica |access-date=2026-03-22}}</ref>

The Lightning Network is intended to address this and to make peer-to-peer payments more practical.<ref>{{cite web |url=https://arstechnica.com/tech-policy/2018/02/bitcoins-lightning-network-a-deep-dive/ |title=Bitcoin has a huge scaling problem—Lightning could be the solution |last=Lee |first=Timothy B. |date=2018-02-04 |website=Ars Technica |access-date=2026-03-22}}</ref>

Several cryptocurrency wallets offer support for the Lightning Network, including Phoenix, [[Cash App]], Muun, Zeus, Strike and Breez.<ref>{{cite web |url=https://www.hedgewithcrypto.com/best-bitcoin-lightning-wallets/ |title=9 Best Bitcoin Lightning Wallets 2025 |website=HedgewithCrypto |date=2025-02-21 |access-date=2026-03-22}}</ref>

The Lightning Network is being used in several businesses in the United States, including Steak N Shake, and some Square Terminals<ref>{{Cite web |last=Zimmerman |first=Micah |date=2025-11-10 |title=Square Bitcoin Payments Goes Live Bringing BTC To Millions |url=https://bitcoinmagazine.com/business/square-bitcoin-payments-go-live-today |access-date=2026-06-11 |website=bitcoinmagazine.com |language=en-US}}</ref>
