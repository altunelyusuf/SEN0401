# Chapter 13 assets - provenance and licences (v1.0.0)

Every file was downloaded on 2026-10-15 with curl. Wikimedia Commons (upload.wikimedia.org original) returned HTTP 429 with a Retry-After of 600 s for hours, because the IP is shared with two other builders; two pictures planned from Commons (the Gage Skidmore photograph of a 25 BTC Casascius coin, curid=81281725, and the Bitcoincharts Mt. Gox chart, curid=15422071) could not be fetched in time, a background loop retried every 660 s and was stopped, and both were replaced by Flickr photographs found through the Openverse index (api.openverse.org) from the Flickr static host. Authors, licences and dates were read from Openverse, the Commons file metadata or the Flickr page on the same day. Where Flickr gives only an account name and no personal name, the account name is credited as given and this is stated. CC BY, CC BY-SA files keep their credit here and wherever the picture is shown.
