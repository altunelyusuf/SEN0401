# Chapter 11 story pictures - provenance with checksums (v1.1.0)

Adds the sha256 (first 16) of each picture file that the stories use, as the story check reads it, and three lossless PNG copies (`photo_satoshi_bust_budapest.png`, `photo_children_sandpit.png`, `photo_signet_ring.png`) of the JPEG files of v1.0.0 (same pixels), made so that the picture check's re-encoding control can run on the deck. Authors, licences and dates are those of `ASSETS_PROVENANCE_v1_0_0.md` (the Commons API or the Openverse index of Commons and Flickr, read on 2026-10-15); the signet ring of Ramesses II is CC0 1.0 from Flickr.
