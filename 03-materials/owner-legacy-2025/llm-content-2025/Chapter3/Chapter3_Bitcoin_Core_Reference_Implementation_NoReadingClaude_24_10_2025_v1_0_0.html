Quick Installation Guide

$ cd bitcoin
$ git tag  # list releases
$ git checkout v25.0  # latest stable
$ ./autogen.sh && ./configure && make -j$(nproc)
$ sudo make install  # installs bitcoind, bitcoin-cli
# Download from bitcoincore.org
# Verify signatures and checksums
$ bitcoind -daemon
$ bitcoin-cli getblockchaininfo

💡 Use prune=5000 for constrained disks, txindex=1 for full transaction queries.

🏗️ Bitcoin Core Architecture

Bitcoin Core is organized into four main layers. Understanding this architecture is crucial for development.

🌐 Network Layer (P2P)

Handles peer discovery, connection management, message propagation, and DoS protection.

⚖️ Consensus Layer (Validation)

Transaction validation, block validation, script execution, and consensus rule enforcement.

💾 Storage Layer (Database)

Blockchain storage in blk*.dat, UTXO set in LevelDB chainstate, and optional transaction index.

👛 Wallet & RPC Layer

Key management, transaction creation, coin selection, and JSON-RPC API server.

⚙️ Node Setup & Configuration

1. Create bitcoin.conf

# ~/.bitcoin/bitcoin.conf

# RPC Credentials (CHANGE THESE!)
rpcuser=bitcoinrpc
rpcpassword=YOUR_SECURE_PASSWORD

# Resource-constrained setup
prune=5000              # Keep only 5GB
maxconnections=15       # Limit peers
maxmempool=200          # 200MB mempool

# Full-index backend (optional)
# txindex=1             # Enable full tx lookup

2. Configuration Options

Option Purpose Recommended Value
prune Reduce disk space by deleting old blocks 5000 (5GB) for constrained systems
txindex Maintain index of ALL transactions 1 for API/dev, 0 otherwise
maxconnections Limit peer connections 15-30 for limited bandwidth
dbcache Database cache size (MB) 450-4096 depending on RAM

3. Running the Node

# Start in foreground (testing)
$ bitcoind -printtoconsole

# Start as daemon (production)
$ bitcoind -daemon

# Check status
$ bitcoin-cli getblockchaininfo

# Stop the node
$ bitcoin-cli stop

    Exercise 1: Query Node Status
    
            
    
                
    from bitcoin.rpc import RawProxy

# Create connection
p = RawProxy()

# Get blockchain info
blockchain_info = p.getblockchaininfo()
block_count = blockchain_info['blocks']
print(f"Total blocks: {block_count}")

# Get network info
network_info = p.getnetworkinfo()
connections = network_info['connections']
print(f"Peer connections: {connections}")
    
            
    
            
            
    Exercise 2: Analyze Block Transactions
    
            
    
                
    from bitcoin.rpc import RawProxy

p = RawProxy()
block_height = 277316

# Get block hash and data
block_hash = p.getblockhash(block_height)
block = p.getblock(block_hash)
tx_list = block['tx']

print(f"Block #{block_height} has {len(tx_list)} transactions")

# Analyze first 5 transactions
for i, tx_id in enumerate(tx_list[:5]):
    raw_tx = p.getrawtransaction(tx_id)
    decoded = p.decoderawtransaction(raw_tx)
    
    num_inputs = len(decoded['vin'])
    num_outputs = len(decoded['vout'])
    print(f"TX {i+1}: {num_inputs} inputs, {num_outputs} outputs")
