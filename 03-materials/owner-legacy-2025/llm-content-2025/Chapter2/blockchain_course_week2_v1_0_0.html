Bitcoin Overview

The Bitcoin system represents a revolutionary approach to digital currency, fundamentally different from traditional banking and payment systems. Instead of relying on a central trusted authority, Bitcoin achieves trust as an emergent property from the interactions of different participants in the network.

🔑 Key Concept: Decentralized Trust

Unlike traditional banks that act as trusted intermediaries, Bitcoin distributes trust across thousands of network participants. No single entity controls the system, making it resistant to censorship and central points of failure.

Bitcoin Transactions

A Bitcoin transaction is a signed data structure that transfers value from transaction inputs to outputs. Transactions are not encrypted—they're public records that anyone can view and verify.

📖 Real-World Example: Buying a Cup of Coffee

Scenario: Alice wants to buy a cup of coffee from Bob's Cafe using Bitcoin.

  • Price: $1.50 USD = 0.015 BTC
  • Alice's Balance: 0.10 BTC (received from Joe)
  • Payment: 0.015 BTC to Bob
  • Change: 0.085 BTC back to Alice
  • Fee: 0.0005 BTC (half a millibitcoin)

Transaction Structure

Component Description Example
Inputs References to previous transaction outputs 0.10 BTC from Joe
Outputs New destinations for the bitcoin value 0.015 to Bob, 0.085 to Alice
Digital Signature Proof of ownership from the sender Alice's signature
Transaction Fee Implicit (input - outputs) 0.0005 BTC

🔐 The UTXO Model

Unspent Transaction Outputs (UTXO) are the fundamental building blocks of Bitcoin accounting:

  • Bitcoin doesn't have "account balances" like traditional banks
  • Instead, your wallet's balance is the sum of all UTXOs you control
  • Each UTXO can only be spent once (prevents double-spending)
  • When spent, UTXOs are consumed entirely and create new UTXOs

💡 Key Insight: Making Change

Just like physical currency, Bitcoin transactions often require "change." If you have a 0.10 BTC UTXO and need to pay 0.015 BTC, the transaction creates two outputs: 0.015 BTC to the recipient and 0.085 BTC back to you as change. The change goes to a new address in your wallet for privacy reasons.

Bitcoin Mining

Mining is the process by which transactions are verified and added to the blockchain. It serves two critical purposes: securing the network through computational work and distributing new bitcoins according to a fixed schedule.

The Mining Process

1

Collect Transactions

Gather unconfirmed transactions from the network

2

Validate

Verify all transactions follow consensus rules

3

Build Block

Create new block with transactions

4

Proof-of-Work

Find solution to cryptographic puzzle

5

Broadcast

Share valid block with network

6

Earn Reward

Collect block reward + fees

🧩 Proof-of-Work: The Sudoku Analogy

Proof-of-Work is like a giant competitive sudoku game:

  • Asymmetric Difficulty: Very hard to solve, but easy to verify
  • Target Time: Automatically adjusts to maintain ~10 minute solution time
  • Competition: Thousands of miners race simultaneously
  • Reward: Winner gets newly minted bitcoin + transaction fees

✅ Block Confirmations

Each block added on top of your transaction increases its security:

  • 0 Confirmations: Transaction broadcast, not yet mined
  • 1 Confirmation: Included in a block (10 min average)
  • 3 Confirmations: Safe for small purchases (~30 min)
  • 6 Confirmations: Considered final (~60 min)
  • 6+ Confirmations: Essentially irreversible

Design Challenge: Build a Transaction Confirmation Monitor

Objective: Design an AI agent that monitors Bitcoin transactions and notifies users about confirmation status.

Requirements:

  • Monitor blockchain for specific transaction IDs
  • Track confirmation count (0, 1, 3, 6+)
  • Send notifications at key milestones
  • Estimate time to next confirmation
  • Handle blockchain reorganizations

Implementation Ideas:

class TransactionMonitor:
    def __init__(self, tx_id):
        self.tx_id = tx_id
        self.confirmations = 0
        
    async def monitor(self):
        while self.confirmations < 6:
            # Query blockchain API
            status = await self.check_status()
            
            if status.confirmations > self.confirmations:
                self.confirmations = status.confirmations
                self.notify_user()
            
            await asyncio.sleep(60)  # Check every minute
            
    def notify_user(self):
        milestones = {
            1: "Transaction confirmed!",
            3: "Transaction secure (3 conf)",
            6: "Transaction final (6 conf)"
        }
        if self.confirmations in milestones:
            send_notification(milestones[self.confirmations])
