Testing CQ-10: What signature schemes are supported?
Category: Advanced
Results: 3 rows
Status: ✓ PASS
Sample results:
  1. http://example.org/blockchain/transactions#ECDSASignature | ECDSA Signature | ECDSA is the digital signature scheme Bitcoin used exclusively until Taproot. It uses the secp256k1 elliptic curve and produces signatures with two components (r, s). Each signature is 71-72 bytes in DER encoding. ECDSA signatures commit to transaction data and SIGHASH type.
  2. http://example.org/blockchain/transactions#SchnorrSignature | Schnorr Signature | Schnorr signatures are an alternative signature scheme using the same secp256k1 curve. They are 64 bytes (smaller than ECDSA), support linear aggregation enabling efficient multisig, allow batch verification, and have provable security. Schnorr is used exclusively in Taproot (witness version 1).
  3. http://example.org/blockchain/transactions#AggregatedSignature | Aggregated Signature | Schnorr signatures support linear aggregation where multiple signatures can be combined into a single signature that validates the combined statement. This makes multisig transactions indistinguishable from single-sig, improving privacy and reducing transaction size.
