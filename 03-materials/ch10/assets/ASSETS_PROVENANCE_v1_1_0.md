# Chapter 10 story pictures - provenance with checksums (v1.1.0)

Adds the sha256 (first 16) of each picture file that the stories use, as the story check reads it, and four lossless PNG copies of the Commons JPEG files of v1.0.0 (same pixels), made so that the picture check's re-encoding control can run on the deck. Authors, licences and dates are those of `ASSETS_PROVENANCE_v1_0_0.md`, read from the Commons API on 2026-10-15.
